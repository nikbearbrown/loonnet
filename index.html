A year on the Chain

Each short chapter turns one biological fact into a playable consequence, from choosing a spring nest site to making the fall takeoff. Play in your browser with no installation required.

Browser-based · WebGL2

Developed based on concepts and chapters from Generative AI for Game Development: Crafting Narrative Worlds with Machines by Shesh Narayan Gupta · DOI: 10.1007/979-8-8688-2439-5

Games are the front door

LoonNet connects museum-floor learning with conservation work: interactive chapters paired with seasonal drone, acoustic, and underwater field capture, plus practical tools for annotation, loon detection and counting, habitat-change review, and responsible sharing.

Play a consequence

Visitors learn why nesting height, water clarity, boat wakes, and open water matter by making decisions rather than reading labels alone.

Work with real observations

Whitefish Chain footage and annotated imagery connect the public-facing experience to the actual lakes, birds, habitats, and seasonal conditions.

Build tools the Center can keep

Usable, reviewable tools for non-technical teams, with transparent results and human expertise kept in the decision loop.

This game needs WebGL2

Your browser is reporting that WebGL2 is turned off. It is on by default in every current browser, so one of these usually fixes it. Reload this page afterwards.

Chrome
Settings → System → turn on Use graphics acceleration when available → Relaunch. If it is already on, open chrome://gpu and check the WebGL2 line; an extension that blocks fingerprinting may be disabling it, so try an Incognito window.
Edge
Settings → System and performance → turn on Use graphics acceleration when available → Restart.
Firefox
Settings → General → Performance → untick Use recommended performance settings → tick Use hardware acceleration when available. If it still fails, open about:config and make sure webgl.disabled is false.
Safari
Safari 15 and later has WebGL2 on by default; update macOS or iOS if you are older than that. On older versions: Safari → Settings → Advanced → Show Develop menu, then Develop → Experimental Features → WebGL 2.0.
Still stuck?
Update the browser, or try another one. Firefox keeps WebGL working even with hardware acceleration off.
